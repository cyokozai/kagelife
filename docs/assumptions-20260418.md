## #4 の決定詳細

WASMビルドはEbitengineで技術的に可能だが、`fsnotify`（ファイル監視）がブラウザ環境では動作しないため、
ホットリロードのコア機能と根本的に相性が悪い。

- **MVP**: macOS (arm64/amd64) + Linux (amd64/arm64) のネイティブバイナリ
- **V2以降**: WASMビルドを検討（ただし「ファイルアップロード型プレビューア」として別機能扱い）
