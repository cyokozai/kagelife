# Phase 2: Solution Space — KageLive

## 価値提案

> **KageLiveは、Ebitengine/Kageシェーダーをファイル保存だけでリアルタイム反映し、
> キーボードで瞬時に切り替えられる、Go開発者のためのVJライブコーディングツールです。**

## North Star Metric

> **「ファイル保存からシェーダー反映までのレイテンシが体感ゼロ（< 200ms）」**

## Opportunity Solution Tree

```mermaid
flowchart TD
    O["🎯 Outcome\nKageシェーダーでVJパフォーマンスを快適にこなす"]

    O --> O1["🔵 Opportunity 1\nシェーダーの切り替えが瞬時にできる"]
    O --> O2["🔵 Opportunity 2\n書いたコードがすぐ画面に反映される"]
    O --> O3["🔵 Opportunity 3（V2）\n複数シェーダーを重ねられる"]
    O --> O4["🔵 Opportunity 4（V2）\nパラメータをライブ調整できる"]

    O1 --> S1["✅ MVP: キーボードで番号指定してシェーダー切替\n（1〜9キーなど）"]
    O1 --> S2["✅ MVP: shaders/ディレクトリのkageファイルを\n起動時に全ロード"]

    O2 --> S3["✅ MVP: fsnotifyでファイル監視\n→ 保存時に自動再コンパイル"]
    O2 --> S4["✅ MVP: Time / Resolution Uniformを\n毎フレーム自動注入"]
    O2 --> S5["✅ MVP: コンパイルエラー時は\n前のシェーダーを維持"]

    O3 --> S6["🔜 V2: DrawRectShaderで最大4枚を合成\nブレンドモード対応"]
    O4 --> S7["🔜 V2: ImGui or tviewで\nUniformパラメータUI"]
    O4 --> S8["🔜 V2: タップBPM → Uniformに流す"]
```
